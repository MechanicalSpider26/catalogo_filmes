# Projeto Cinema - Aplicação Web com Flask

Este é um projeto acadêmico de aplicação web para gerenciamento e visualização de um catálogo de filmes. A aplicação foi desenvolvida em Python utilizando o microframework **Flask** para a renderização de rotas e templates via **Jinja2**, com persistência de dados em um banco de dados **SQLite** local.

O repositório já inclui o arquivo `cinema.db` pré-populado com dados sobre filmes, permitindo a execução e testes locais imediatos após o clone do projeto.

---

## Tecnologias Utilizadas

* **Linguagem:** Python
* **Framework Web:** Flask
* **Template Engine:** Jinja2
* **Banco de Dados:** SQLite (`cinema.db`)
* **Front-end:** HTML5, CSS3

---

## Como Executar o Projeto Localmente

Certifique-se de ter o **Python 3.x** instalado em sua máquina.

Rode o comando "pip install -r requirements.txt"

O Banco de Dados ja está pré populado com dados de alguns filmes

**Para rodar execute o app.py**
